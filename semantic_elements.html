what are semantic elements

semantic elements are those elements that have a meaning and they describe the content of the element

examples of semantic elements

examples of semantic elements include header, footer, main, section, article, aside, nav

what is the use of semantic elements

semantic elements are used to give meaning to the content of the element and they help in improving the accessibility of the website
